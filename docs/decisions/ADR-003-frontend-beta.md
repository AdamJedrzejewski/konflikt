# ADR-003: Frontend — wersja beta

**Data:** 2026-05-04  
**Status:** ACCEPTED

## Decyzja

Wdrożenie oznaczone jako **wersja beta** — wyraźna informacja w UI i regulaminie.

## Uzasadnienie

- System będzie testowany przez radców na rzeczywistych (anonimizowanych) stanach faktycznych
- Beta label = transparentność co do stanu systemu
- Obniża ryzyko prawne i odpowiedzialność na etapie kalibracji
- Daje przestrzeń na iterację bez presji "produkcji"

## Wymagania UI (beta)

- Banner/badge "BETA" widoczny na każdej stronie
- Disclaimer przed pierwszą analizą: narzędzie wspomagające, nie zastępuje oceny radcy
- Formularz feedbacku po każdej analizie (opcjonalny)
- Wyraźne oznaczenie poziomu pewności w wynikach
